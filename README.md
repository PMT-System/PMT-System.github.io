# PMT company workspace

Target website: https://pmt-system.github.io/

This is a staged frontend release. The website displays **Workspace setup in progress**; team sign-in and workflows are not enabled yet.

The proposed Supabase backend update was blocked by automatic approval review. No live database migration or Edge Function deployment has been applied. The full system is not production ready.

Local unit/browser tests and PostgreSQL/WASM migration, chat-access and bug-workflow tests have passed. These are not a substitute for live Supabase and external-integration verification.

The reviewed source bundle is `PMT-source.zip`. It contains the full source, proposed SQL and testing instructions, without credentials or company database records. Backend scripts require independent review and the applicable authorization before deployment.
