PMT System

Privacy Policy

Last updated: 19 October 2026

PMT System is a company workspace for project management, Android build management and QA bug tracking. The public website is currently a setup page. The workspace features described below are being prepared for release; this notice does not mean they are all live.

Information used by the workspace

When enabled, the workspace uses account email addresses, names, roles and active status; project and team assignments; build metadata and APK files; bug reports, screenshots and attachments; QA summaries; team and direct messages; timestamps and activity history. Users should only enter information they are authorised to share with their company team.

Purpose and access

This information supports sign-in, project collaboration, build distribution, QA reporting, auditing and administration. Access is intended to follow company-assigned roles and project membership. Company administrators have broader management access. Team messages and reports should not be treated as a personal private messaging service.

Google Drive access

An authorised company account may connect Google Drive to store APK binaries when Supabase storage is unsuitable or unavailable. The integration requests the narrow drive.file permission to manage files created or explicitly opened with this app; it does not request access to all files in the account. The app creates or uses a private APK folder. Build records retain provider references and checksums so authorised users can download and verify the associated file.

Older APK binaries are eligible for removal only through the configured Admin approval workflow. The latest two builds and builds protected by active QA checks have deletion protections. Removing an APK binary is intended to preserve its build record, bug reports and QA history.

Optional AI features

When a user invokes an AI report or summary action, relevant report text is sent to the configured AI provider to generate a draft. Groq and OpenRouter are the currently verified provider connections; live workspace integration is pending. OpenRouter forwards the request to a selected model provider. The OpenRouter integration requests that providers which collect data be excluded, although availability then depends on compatible capacity. Other providers' processing is governed by their own policies. Google Drive APK binaries are not automatically sent to these AI services. AI bug drafts require QA review and approval before being saved as bug reports.

Google user data is used to provide the requested Drive file-management features. It is not sold, used for advertising, or used by PMT to train general-purpose AI models. Do not include passwords, API keys or unnecessary personal information in reports, messages or AI prompts.

Service providers and storage

GitHub Pages hosts the public frontend. Supabase provides the intended authentication, database, private storage and backend services. Google Drive provides optional APK storage. Groq and OpenRouter provide optional AI processing. Those services may process technical information under their respective policies. The static frontend is public source code; private runtime credentials are kept separately from public website files.

Retention and deletion

Project reports, activity records and QA history are intended to remain available for company work and audit needs; there is no general automatic report-expiry schedule. Archiving a record does not necessarily erase it. APK binary retention is separate from report retention. Contact the company administrator about access, correction, export or deletion requests. Deletion may require review of related records, legal or business obligations, and separately held backups.

Security and browser storage

The workspace implementation uses authenticated access, database row permissions, private file storage and short-lived download access where supported. Sign-in sessions and work-in-progress browser state may be stored on the user's device. Do not use a shared browser profile for confidential company work. No system can guarantee absolute security. The public setup page does not provide team sign-in until release checks are complete.

Disconnecting Google Drive

The Google account owner can revoke this app's access from Google Account third-party connections. Revocation stops future access with that authorisation; it does not itself delete existing files or company records. Contact the administrator if stored files or references also need removal.
